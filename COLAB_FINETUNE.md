# Fine-Tuning Founder AI on Google Colab

This guide describes how to fine-tune an open-source LLM (such as Llama 3.2 3B) using **Google Colab** and **Unsloth**, and export it directly as a GGUF file for local offline execution.

---

## Step 1: Open Google Colab and Setup GPU
1. Go to [Google Colab](https://colab.research.google.com/).
2. Click **New Notebook**.
3. In the top menu, go to **Runtime > Change runtime type**.
4. Set the **Hardware accelerator** to **T4 GPU** (or any higher GPU if you have Colab Pro).
5. Click **Save**.

---

## Step 2: Upload Files
In the left sidebar of Google Colab, click the **Folder icon** to view the filesystem. Drag and drop the following files into the main directory:
1. `dataset.json` (Generated by `generate_dataset.py`)
2. `train.py` (The Unsloth training script)

---

## Step 3: Run the Training
Create a new code cell in Colab, paste the following commands, and execute it:

```bash
# 1. Install Unsloth and training dependencies
!pip install "unsloth[colab-new] @ git+https://github.com/unslothai/unsloth.git"
!pip install --no-deps trl peft loralib sentencepiece subword-nmt

# 2. Run the fine-tuning script
!python train.py
```

*Note: The script will load the Llama 3.2 3B base model, configure LoRA adapters, train on your dataset for ~2.5 epochs (60 steps), and export it.*

---

## Step 4: Download Your GGUF Model
Once training completes, the script will output two GGUF models:
* `founder_ai_model_q8/unsloth.Q8_0.gguf` (Highly accurate 8-bit quantized model, recommended for M1/M2/M3 Macs or PCs with 16GB+ RAM)
* `founder_ai_model_q4/unsloth.Q4_K_M.gguf` (Fast 4-bit quantized model, optimized for low memory usage)

In the Colab file sidebar, navigate to the output folders, click the three dots next to the `.gguf` file, and select **Download**.

---

## Step 5: Load the Model Locally
Move the downloaded `.gguf` file into your local desktop application project folder and update your app loader configuration to use it.
